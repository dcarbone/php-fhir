Typed PHP for HL7 FHIR, generated from the spec.

php-fhir reads the official FHIR XSD schemas and produces a fully-typed PHP library: a model for every FHIR type, JSON and XML (de)serialization, validation, and a ready-to-use REST client.

Get the pre-built package Run the generator

What you get

Every FHIR type

Resources, data types and primitives as plain, fully-typed PHP classes.

JSON & XML

Serialize and unserialize either format, with configurable behavior.

Validation

Rules derived from the schema, applied to the generated types.

Profiles

Optionally generate classes for profiles such as US Core, nested like the base types, validated by the regular rules and picked automatically from meta.profile when parsing.

REST client

A client for talking to FHIR servers, generated per version.

Custom output

Choose your namespace, versions and behavior when you generate it yourself.

Supported FHIR versions

DSTU1DSTU2STU3R4R4BR5R6 (pre-release)

Requires PHP 8.1 or newer.

Quick start

Just want the models? Install the pre-built, always-in-sync package:

composer require dcarbone/php-fhir-generated

Want to generate your own?

composer require dcarbone/php-fhir

mkdir -p fhir-schemas/R4
curl -Lo fhir-schemas/R4.zip https://hl7.org/fhir/R4/fhir-codegen-xsd.zip
unzip fhir-schemas/R4.zip -d fhir-schemas/R4

Need profiles such as US Core? Point a version at local implementation guide packages, and the packages they depend on; see the Profiles guide.

The Getting Started and CLI Usage guides cover the rest.
